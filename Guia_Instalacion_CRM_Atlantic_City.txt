CRM ATLANTIC CITY
=================

REQUISITOS
- Windows 10/11 para los instaladores .bat.
- Node.js 22.13 o superior y npm.
- Navegador web actualizado.
- Permisos de escritura en la carpeta del proyecto.

INSTALACIÓN
1. Descomprima el ZIP en una carpeta local.
2. Ejecute instalar.bat.
3. Espere a que finalice la instalación de dependencias.
4. Ejecute iniciar.bat.
5. Abra http://localhost:3000.
6. Configure el primer administrador con una contraseña de al menos 12 caracteres.

INSTALACIÓN MANUAL
Desde la carpeta raíz:
  npm install
  node backend/scripts/setup.js
  npm start

BASE DE DATOS
La base de datos se crea automáticamente en:
  database/atlantic_crm.db
La ubicación se puede cambiar mediante SQLITE_FILE en backend/.env.
El esquema se encuentra en backend/database/sqlite-schema.sql.

DATOS DE DEMOSTRACIÓN (SOLO DESARROLLO)
PowerShell:
  $env:SEED_DEMO_DATA="true"
  npm run seed:demo

CMD:
  set SEED_DEMO_DATA=true && npm run seed:demo

- Silver: desde 0 puntos.
- Gold: desde 500 puntos.
- Platinum: desde 1.500 puntos.

RESPALDOS
Detenga el CRM antes de copiar manualmente database/atlantic_crm.db.
Guarde los respaldos en una ubicación segura distinta del equipo del servidor.
Proteja backend/.env: contiene secretos.

DIAGNÓSTICO
Abra http://localhost:3000/api/health.
La respuesta correcta incluye ok:true y engine:SQLite.
